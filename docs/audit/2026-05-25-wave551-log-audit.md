## 🔴 Critical: backend timeout 06:41:04 today

```
2026-05-24 06:41:04.959 [ERROR] FATAL: Krab Ear: backend недоступен —
Не удалось подключиться к backend: backend (launchd Variant B) не отвечает
за 20 сек — проверь `launchctl print gui/501/ai.krab.ear.backend`
```

**Direct evidence for Wave 533 hypothesis**: backend cold start exceeds the
supervisor's 20-second timeout on fresh boot (post macOS auto-update). Wave 422
bumped this to 15s (or 20s — discrepancy worth investigating in Wave 533 doc).

Repro pattern:
1. macOS auto-update reboot at ~14:04 CEST (and morning unscheduled reboots)
2. Backend launches via launchd KeepAlive but MLX warmup + HF cache check takes >20s
3. Swift agent supervisor probe expires → FATAL toast
4. User must dismiss toast and wait additional ~30s before agent reconnects
