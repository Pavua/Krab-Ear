## 2. Спека токенов (предложение; все значения в `KrabEarTheme`)

| Радиусы | 12 / 8 | 12 / 8 / 6 (мелкие чипы) | |

| Минимум зоны клика | — | 32×32 | |
| Граница карточки | 10–15 % alpha | 1 pt, ≥ 3:1 контраст к фону | |

Цвета: светлая/тёмная — динамические `NSColor`; пары «текст/фон» ≥ **4.5:1** (WCAG AA),
крупный ≥ 3:1; проверка автотестом (вычисление luminance по обоим `NSAppearance`).
Статус = **цвет + иконка + слово** (напр. «Готов», «Ошибка»), никогда только цвет.
Токены Figma↔Swift (#2202) не трогаем; изменения значений токенов фиксируем в этом документе,
синхронизацию с Figma делает владелец токенов отдельно.

Правила раскладки (обязательные, проверяются тестами):
- Любой вертикальный `NSStackView`: `alignment = .leading` **и** явная ширина детей
  (`child.width == stack.width - 2*padding`), иначе subview центруется по intrinsic.
- Контент вкладки живёт в `NSScrollView`; минимальная ширина окна — единый `Layout.windowMinWidth`.
- Один заголовок экрана + карточки; в карточке не более одной «главной» кнопки (prominent).
- Состояния: пусто (иконка + 1 фраза + действие), загрузка (индикатор + текст, ≤ 150 мс
  без показа, чтобы не мигало), ошибка (что случилось + что делать + кнопка «Повторить»).
- Анимации через `Motion.animate` (учитывает Reduce Motion); бесконечных пульсаций нет,
  кроме индикатора записи.

Доступность: у каждого интерактивного контрола `accessibilityLabel` по-русски (глагол +
объект: «Начать диктовку»), порядок обхода VoiceOver сверху вниз, фокус-кольцо не
скрывать, все действия доступны с клавиатуры, динамические статусы — `NSAccessibility.post(announcement)`.

## 4. Как проверяем без боевого запуска

- Офлайн-рендер: `NSView.bitmapImageRepForCachingDisplay` → PNG в scratchpad из XCTest
  (светлая/тёмная: `view.appearance = NSAppearance(named:)`), смотрим через Read.
- Тесты раскладки на ширинах окна **640 / 860 / 1280** (образец —
  `DiagnosticsTabLayoutTests`): нет схлопнутых карточек, нет выхода за границы, минимальные размеры.
- Гейты (AST/rg, как принято в репо): `ipcClient.call` вне `global`/`Task`, `runModal`
  вне allowlist, `ofSize:` < 12 вне темы, новые таймеры.
- Время построения вью — с оговоркой по загрузке CI-машины (порог с запасом, не флаки).
- Живой агент, сборка `.app`, перезапуск, микрофон/TCC — **только по слову владельца**.

## 5. Риски и ограничения исполнения

- Машина: swap ≈ 4.1 из 5.1 ГБ занято. В этом worktree нет `.build`, первая `swift build`
  холодная и тяжёлая → собирать по одной, не параллелить, не запускать рядом другие тяжёлые задачи.
- Крупные файлы (`HistoryPanelController.swift` 2712 строк, `+Settings` 1918) — править
  маркерными правками с проверкой уникальности и длины (известный инцидент).
- Рост шрифтов увеличит высоту карточек: вкладки обязаны скроллиться, иначе клип.
- Глиф-гейт: новые non-ASCII символы сверять с существующими в `native/`.
