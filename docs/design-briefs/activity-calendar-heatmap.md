# ТЗ: Календарь активности (GitHub-style heatmap) в Krab Ear

## Цель
Добавить НОВУЮ самодостаточную секцию **«Календарь активности»** во вкладку **История** (History tab) приложения Krab Ear — GitHub-подобную тепловую карту: сетка 7 строк (дни недели) × N столбцов (недели), где каждая клетка окрашена по уровню активности записи за день (0–4). Под сеткой — строка-сводка: текущий стрик, самый длинный стрик, всего активных дней. Бэкенд УЖЕ полностью готов — нужен только Swift-фронт.

- НЕ ломай glyph-guard: любой текст (включая эмодзи/кириллицу) — через существующие безопасные паттерны; не вызывай CoreText glyph-build синхронно на первом показе.
- Уважай Reduce Motion (через `KrabEarTheme.Motion.animate()` если делаешь анимации).

## IPC-контракт (УЖЕ существует, переиспользуй — anti-rebuild)
Метод: **`get_activity_calendar`**, params: `{"months": <int, по умолчанию 12>, "include_svg": <bool, опционально>}`.
Возвращает dict:
```json
{
  "days": { "2026-06-17": {"date": "2026-06-17", "recordings": 3, "duration_min": 12.5, "words": 420, "level": 2}, ... },
  "weeks": [ [ {day or null}, ...7 элементов... ], ... ],   // сетка: список недель, каждая = 7 ячеек (Пн..Вс), null = нет дня
  "total_active_days": 87,
  "longest_streak": 14,
  "current_streak": 5
}
```
- `level`: целое **0–4** (0 = нет активности, 4 = максимум) → 5 оттенков.
- `weeks` — это готовая сетка для отрисовки (столбцы слева-направо = недели от старых к новым; строки сверху-вниз = дни недели). Ячейка может быть `null` (вне диапазона) → рисуй пустую/прозрачную клетку.
- Эталон вызова IPC off-main: посмотри `HistoryPanelController+Analytics.swift` (как там зовётся `get_analytics_dashboard` и парсится ответ) и `HistoryPanelController+Settings.swift` для паттерна секции.

## Визуальная спецификация (твоя зона — дизайн)
- **Сетка heatmap**: клетки — скруглённые квадраты (~11×11pt, gap ~3pt), 7 строк × N недель. Рисуй нативно (CALayer-грид как в `ConversationViewController+LevelMeter.swift` `MicLevelMeterView` — 20 CALayer-баров; используй тот же подход для производительности, НЕ WKWebView/SVG-embed).
- **5 оттенков по level 0–4**: построй палитру на основе `KrabEarTheme` (акцентный цвет проекта) — level 0 = очень бледный/нейтральный фон клетки, level 4 = насыщенный акцент; 1–3 = промежуточные ступени. Подбери эстетичную монохромную акцент-шкалу в духе Liquid Glass темы проекта (см. `KrabEarTheme.swift`).
- **Подписи**: слева — сокращения дней недели (Пн/Ср/Пт через одну строку, как в GitHub); сверху — подписи месяцев над соответствующими столбцами.
- **Hover-tooltip** на клетке: «<дата>: N записей, M мин, K слов» (через `NSView.toolTip` или лёгкий tracking-area popover — без модалок).
- **Строка-сводка** под сеткой: «🔥 Текущий стрик: 5 дн · Рекорд: 14 дн · Активных дней: 87» (адаптируй формулировки/иконки под тему; склонения «день/дня/дней» корректно).
- Секция-контейнер — `CollapsibleSectionView` (как остальные секции History/Settings), заголовок «Календарь активности», сворачивается, состояние персистится (UserDefaults паттерн `CollapsibleSection_{id}` — как у других секций).
- Пустое состояние (нет истории / privacy mode): аккуратный плейсхолдер «Нет данных активности» вместо пустой сетки. Бэкенд отдаёт пустой `weeks`/`days` при privacy mode — обработай.
