# Design Brief: секция «Модель STT в памяти» — понятные подписи и честная доступность

Дата: 2026-09-03. Исполнитель: Gemini 3.8 Flash (High) через agy. Гейт: Claude.
Файл: `native/KrabEarAgent/Sources/KrabEarAgent/HistoryPanelController+STTModelMemory.swift`.
Правки НЕ коммитить. Ветка уже выбрана.

## Проблема (слова владельца)

«Что это за вариант "действительно выгружать по простою"? И так же есть галочка
выгружать или нет, не совсем понятно.»

Он прав: две строки описывают одно, и обе врут о состоянии.

| строка сейчас | ключ | что на самом деле |
|---|---|---|
| «Выгружать после простоя» + шаг 60 мин | `gigaam_idle_unload_sec` | СРОК простоя |
| «Действительно выгружать по простою» | `memory_conductor_enforce_gigaam` | ГЛАВНЫЙ выключатель |

Пока второй выключен (а он выключен по умолчанию), дирижёр памяти только пишет в
журнал «выгрузил бы» и **не выгружает ничего**. То есть «60 мин» выглядит рабочей
настройкой, но не делает ничего — классическая декоративная настройка.

## Что сделать (ровно это)

1. **Переименовать строки** в ОБОИХ строителях секции — `buildSTTModelMemorySection`
   (Gemini) и `cdBuildSTTModelMemorySection` (Claude Design):
   - «Действительно выгружать по простою» → **«Выгружать модель при простое»**
   - «Выгружать после простоя» → **«Простой до выгрузки»**
   - «Загружать модель при старте» — оставить как есть.
2. **Пояснение под главным выключателем** (в Gemini-версии — параметр
   `description:` у `makeSettingRow`; в CD — отдельная строка-подпись
   `KrabEarTheme.Typography.caption` + `Colors.textSecondary` под строкой):
   «Пока выключено, Krab Ear только записывает в журнал, что выгрузил бы модель.»
3. **Честная доступность**: когда «Выгружать модель при простое» выключен, строка
   «Простой до выгрузки» должна быть **визуально погашена** — `stepper.isEnabled = false`
   и лейбл значения `alphaValue = 0.5`. Включение выключателя — возвращает.
   Состояние применять: (а) при построении секции, (б) в обработчике
   `onSTTEnforceUnloadChanged` после смены. Вынести в общий приватный хелпер
   `applySTTIdleRowAvailability()`, звать из обоих мест.
4. Кнопки «Загрузить сейчас» / «Выгрузить сейчас» — не трогать: они ручные и
   работают независимо от выключателя.

## Что НЕЛЬЗЯ ломать

- Ключи настроек и селекторы — БЕЗ изменений: `onSTTDeviceChanged`,
  `onSTTWarmupOnStartupChanged`, `onSTTIdleUnloadChanged`, `onSTTEnforceUnloadChanged`,
  `onSTTLoadNow`, `onSTTUnloadNow`; ключи `stt_gigaam_device`,
  `stt_warmup_on_startup`, `gigaam_idle_unload_sec`, `memory_conductor_enforce_gigaam`.
  Новых `#selector`, ключей и IPC-вызовов быть не должно.
- `sectionId` обеих секций (`stt_model_memory`, `cd_stt_model_memory`) — без изменений.
- Хелперы `makeSTT…()` остаются общими для обеих версий.
- Никаких новых не-ASCII глифов/эмодзи. `runModal()` запрещён.
- `Tests/` не трогать.
