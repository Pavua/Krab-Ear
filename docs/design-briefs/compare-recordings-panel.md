# ТЗ: Сравнение записей (Compare Recordings) в Krab Ear

## Цель
Дать пользователю сравнить 2+ выбранные записи истории side-by-side: матрица текстового сходства, общие слова, уникальные слова на запись, сравнение длительности/уверенности/языков. Триггер — пункт **«Сравнить выбранные»** в УЖЕ существующем контекстном меню мультивыбора таблицы истории. Бэкенд готов — нужен Swift-фронт.

## Что НЕЛЬЗЯ ломать (жёстко)
- НЕ трогай существующие пункты контекстного меню («Экспортировать выбранное», «Удалить выбранные», «Добавить в коллекцию…») — только ДОБАВЬ новый пункт.
- НЕ используй `runModal()` (Sequoia AppHang — запрещено). Панель сравнения показывай как НЕблокирующий sheet (`presentPanelSheet`-стиль через окно `self.window`) ИЛИ как отдельную секцию/поповер — но без модального run loop.
- ВСЕ IPC строго off-main (AGENT-3), результат на main через `DispatchQueue.main.async`.
- glyph-guard: текст через `NSTextField`, без проблемных Unicode-глифов (● ○ ▶ и т.п.) в `labelWithString`.

## Точка привязки (REUSE — прочитай эти файлы)
Мультивыбор + контекстное меню истории живут в **`HistoryPanelController+ExportSelection.swift`** (там пункты «Экспортировать выбранное» / «Удалить выбранные» / «Добавить в коллекцию…», маппинг `selectedRowIndexes`→`items[row].id`, off-main IPC паттерн). ДОБАВЬ туда новый пункт **«Сравнить выбранные»** (enabled только при выборе ≥2 строк), который собирает `item_ids` и зовёт сравнение. Образец панели/секции — `HistoryPanelController+ActivityCalendar.swift` / `+RecordingInsights.swift` (CALayer/стек, KrabEarTheme).

## IPC-контракт (УЖЕ существует — переиспользуй)
Метод: **`compare_recordings`**, params: `{"item_ids": [<str>, ...]}` (≥2, обязателен). Ответ (`response["result"]`):
```json
{
  "items": [{"id": "...", "title|text": "...", ...}],         // порядок = строки/столбцы матрицы
  "text_similarity_matrix": [[1.0, 0.42, ...], ...],          // N×N, значения 0..1
  "duration_comparison": { ... },
  "confidence_comparison": { ... },
  "language_distribution": { ... },
  "common_words": ["слово", ...],                             // общие для всех
  "unique_words_per_item": [["...","..."], ...]               // по индексу item
}
```
Privacy mode / ошибка: вернётся `{..., "privacy_mode_active": true}` или пустые поля — покажи плейсхолдер «Сравнение недоступно».

## Визуальная спецификация (твоя зона — дизайн)
Панель сравнения (sheet или встроенная секция), содержит:
- **Матрица сходства** N×N: цветные ячейки по значению 0..1 (бледный→насыщенный акцент `KrabEarTheme.Colors.accent`, как heatmap календаря), с подписью % и заголовками строк/столбцов = короткими названиями записей (title или первые слова text). Рисуй нативно (CALayer-грид как в `ActivityCalendarHeatmapView`).
- **Общие слова** — компактный список/облако `common_words`.
- **Уникальные слова на запись** — по колонке/секции на каждую запись.
- (Опц.) краткая сводка длительности/уверенности из `duration_comparison`/`confidence_comparison`.
- Empty/privacy: аккуратный плейсхолдер.
