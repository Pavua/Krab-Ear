## Key Learnings

- **Inline > backgrounded sub-agents.** 60–90% of backgrounded sub-agents die on reboots or compaction events; use inline sequenced tasks or explicit worktrees with `git checkout -b` in the prompt.
- **Keep concurrency ≤ 5.** Beyond 5 parallel agents, merge conflicts and IPC socket contention spike; diminishing returns past that point.
- **LM Studio JIT is the root cause** of rewriter instability — not Claude agent loops or MLX lock contention. The fix is TTL=0 + SSD stay-awake, not code changes.
- **Dead handler audit requires full scope** — Swift-only grep over-counts by ~4×; must check Python test dispatch + direct `_handle_*` calls before removing.
