## 1. Scope

Phase 2.4 is the E2E test suite that validates the full Live Translation pipeline working end-to-end:

```
Fixture audio → WebSocket client → VG /v1/translation/stream → (mock) SeamlessStreaming
    → translation.partial / translation.final events → contract validation → UI render assertions
```

**In scope:**
- Python pytest WebSocket client tests against a local VG server (mocked engine)
- Contract conformance tests (all 7 event types, envelope structure)
- Session lifecycle tests (start → partial stream → final → session_saved → close)
- Error and edge case coverage (disconnect, engine crash, bad contracts, concurrent sessions)
- Integration smoke tests with real SeamlessStreaming (marked `@pytest.mark.integration`, CI-skipped)
- Fixture audio file generation script

**Out of scope:**
- Swift UI automation (no XCTest in this phase; Swift acceptance is handled by Phase 2.2 manual criteria)
- VG unit tests (those belong in the Voice Gateway repo, Phase 2.1 PR)
- Performance benchmarks (separate benchmark matrix in `docs/superpowers/research/`)
- Load testing / concurrent user simulation beyond 2 clients

### 2.2 WebSocket test client

Uses the `websockets` library (pure Python, already compatible with project's asyncio usage):

```python
import asyncio, json, pytest
import websockets

class TranslationWSClient:
    """Thin test client wrapping websockets.connect() for the VG translation endpoint."""

    def __init__(self, url: str, token: str = "test-token"):
        self.url = url
        self.token = token
        self._ws = None

    async def connect(self, source_lang="ru", target_lang="en"):
        self._ws = await websockets.connect(
            self.url, extra_headers={"Authorization": f"Bearer {self.token}"}
        )
        await self.send_config(source_lang, target_lang)

    async def send_config(self, source_lang, target_lang, audio_source="mic"):
        await self._ws.send(json.dumps({
            "type": "stream.config",
            "source_lang": source_lang,
            "target_lang": target_lang,
            "audio_source": audio_source,
        }))

    async def send_audio(self, pcm_data: bytes):
        await self._ws.send(pcm_data)

    async def send_control(self, control_type: str):
        await self._ws.send(json.dumps({"type": control_type}))

    async def recv_event(self, timeout: float = 5.0) -> dict:
        raw = await asyncio.wait_for(self._ws.recv(), timeout=timeout)
        return json.loads(raw)

    async def close(self):
        if self._ws:
            await self._ws.close()
```

### 2.3 Mock SeamlessStreaming engine

A canned-response mock replaces the real model in unit/mocked tests. It accepts PCM frames and emits a scripted sequence of events:

```python
class MockSeamlessStreamingEngine:
    """Returns pre-scripted translation events for test scenarios.
    
    Injected into VG's app state via pytest fixture before server start.
    Implements the same async generator interface as SeamlessStreamingEngine.
    """

    def __init__(self, scenario: str = "ru_to_en_happy_path"):
        self.scenario = scenario

    async def s2tt_stream(self, audio_chunks, source_lang, target_lang):
        for event in CANNED_EVENTS[self.scenario]:
            await asyncio.sleep(0.05)  # simulate minimal latency
            yield event
```

The mock is injected via a pytest fixture that starts a local VG instance with engine override:

```python
@pytest.fixture
async def vg_server(mock_engine_scenario):
    """Start a local VG translation server with mock engine. Yields base WS URL."""
    app = create_vg_app(engine_override=MockSeamlessStreamingEngine(mock_engine_scenario))
    async with run_server(app, port=0) as server:  # port=0 = OS-assigned
        yield f"ws://127.0.0.1:{server.port}/v1/translation/stream"
```

### 3.2 Class `TestSingleSessionHappyPath` (6 tests)

**TC-01 — Basic RU→EN translation**  
Send `ru_to_en_short.wav` PCM → expect at minimum: 1× `translation.partial`, 1× `translation.final`, final text is non-empty, `seq_id` matches across partial and final.

**TC-02 — Language detection event emitted**  
Connect with `source_lang=auto` → after first 1.5s of audio, expect `translation.lang_detected` with `source_lang` in `{ru, en, es}` and `confidence > 0.5`.

**TC-03 — Engine ready emitted before first partial**  
Verify `translation.engine_ready` is the FIRST event received after `stream.config`. `warmup_ms >= 0`. `engine` field is non-empty string.

**TC-04 — Partial replaces in-place (seq_id semantics)**  
Collect all events for one utterance. Assert: multiple `translation.partial` events share the same `seq_id`. The `translation.final` for that utterance has the same `seq_id`. No two `translation.final` events share a `seq_id`.

**TC-05 — Final confidence above threshold**  
For `ru_to_en_short.wav`, the `translation.final` event `confidence` field is either `None` (engine didn't provide) or `>= 0.5`. Test is informational (soft assert) — does not fail if confidence is low, but logs a warning.

**TC-06 — Session saved on clean close**  
Send full `ru_to_en_long.wav`, then send `{"type": "end"}` control. Assert `translation.session_saved` event received before WS closes. `history_id` is non-empty string. `duration_sec > 0`. `word_count_original >= 1`.

### 3.3 Class `TestLanguagePairs` (5 tests)

**TC-07 — ES→EN**  
`es_to_en_short.wav`, `source_lang=es`, `target_lang=en` → final event `lang=en`, text non-empty.

**TC-08 — EN→RU**  
`en_to_ru_short.wav`, `source_lang=en`, `target_lang=ru` → final event `lang=ru`, text non-empty.

**TC-09 — RU→ES**  
Mock scenario scripted for RU→ES. Verify `source_lang=ru`, `target_lang=es` config accepted and final event `lang=es`.

**TC-10 — Unsupported lang pair → error**  
Connect with `source_lang=ja`, `target_lang=zh`. Expect `translation.error` with `code=unsupported_lang_pair` and `fatal=true`. WS closes after error.

**TC-11 — Auto-detect + code switching**  
`code_switching.wav`, `source_lang=auto`. Collect all events. Assert at least one `translation.lang_detected` event. Multiple `translation.final` events may have different `source_lang` fields as language switches — no assertion on content, only structural conformance.

### 3.4 Class `TestPartialAndFinalSemantics` (4 tests)

**TC-12 — Partial text is prefix of final**  
For a single utterance, collect all partials and the final. Assert that the final `text` is not empty and that at least one partial `text` is a prefix or substring of the final (soft — implementation detail of SeamlessStreaming decoder, may not always hold in mock).

**TC-13 — Multiple sequential utterances**  
`ru_to_en_long.wav` (60s, 4+ sentences). Collect events. Assert: at least 3 distinct `seq_id` values appear across `translation.final` events. `translation.session_saved` arrives after last final.

**TC-14 — Pause stops partials; resume restarts**  
Start session, receive first partial, send `{"type": "pause"}`. Wait 1s. Assert no new events arrive during pause window. Send `{"type": "resume"}`. Assert new events resume within 3s.

**TC-15 — Both source and target partials emitted per utterance**  
Collect all `translation.partial` events for one utterance (same `seq_id`). Assert at least one partial has `lang` matching source language and at least one has `lang` matching target language (both STT and MT streaming active).

### 3.5 Class `TestErrorHandling` (4 tests)

**TC-16 — Engine crash → fatal error**  
Mock engine configured to raise `RuntimeError` on second audio chunk. Assert `translation.error` received with `fatal=true`. Assert WS closed by server after error event.

**TC-17 — Inference timeout → non-fatal error, session continues**  
Mock engine scenario: emit `translation.error(code=inference_timeout, fatal=false)`, then continue with normal events. Assert: error event received; WS NOT closed; subsequent `translation.final` events arrive normally.

**TC-18 — Bad client uplink format → server error**  
Send invalid JSON text frame (not a valid control message). Assert server responds with `translation.error` (or WS close code 4400) within 2s. Does not crash server (other clients unaffected).

**TC-19 — Missing Bearer token → 401 / connection rejected**  
Attempt WS connect without `Authorization` header. Assert connection is rejected (HTTP 401 upgrade response or immediate close with code 4401). `TranslationWSClient` raises `websockets.exceptions.InvalidStatusCode` or equivalent.

### 3.6 Class `TestConcurrentSessions` (2 tests)

**TC-20 — Two clients, separate session_ids, no event crossover**  
Open 2 WS connections concurrently, each with a unique `session_id` query param. Send audio on both. Assert events received by client A never contain `session_id` from client B. Assert events received by client B never contain `session_id` from client A.

**TC-21 — Second session evicts first (singleton constraint)**  
If VG enforces a single active translation session: start session A, then start session B. Assert session A receives `translation.error(code=session_evicted)` or WS close. Session B starts normally. If VG allows concurrent sessions: both succeed — test adapts based on VG config.

### 3.7 Class `TestEdgeCases` (2 tests)

**TC-22 — Silent audio → no translation events (or timeout error)**  
Send `silence_only.wav` (5s pure silence). Assert: no `translation.partial` or `translation.final` events within 8s. Either no events at all, or a single `translation.error(code=buffer_overflow, fatal=false)` if VG's VAD timeout fires. No `translation.session_saved` until `end` is sent.

**TC-23 — Sub-second audio → empty final or no events**  
Send `sub_second.wav` (0.5s), then send `end`. Assert: no crash, WS closes cleanly. Either: zero `translation.partial`/`translation.final` events, or one `translation.final` with empty `text=""`. `translation.session_saved` may or may not fire.

## 4. Contract Conformance Validation

Every received event in all 23 tests MUST pass contract validation. A shared pytest autouse fixture applies:

```python
@pytest.fixture(autouse=True)
def validate_all_events(request):
    """Monkey-patch TranslationWSClient.recv_event to auto-validate contracts."""
    from contracts.envelope import parse_and_validate
    original = TranslationWSClient.recv_event

    async def patched(self, timeout=5.0):
        event = await original(self, timeout)
        if "type" in event:
            try:
                parse_and_validate(event)
            except Exception as e:
                pytest.fail(f"Event contract violation: {e}\nEvent: {event}")
        return event

    TranslationWSClient.recv_event = patched
    yield
    TranslationWSClient.recv_event = original
```

This ensures all 7 Phase 2.3 Pydantic models are exercised for every event received across the test suite.

async def test_real_ru_to_en_latency():
    """Real SeamlessStreaming on M4 Max MPS. Assert p50 latency < 1.2s per utterance."""
    async with real_vg_server() as url:
        client = TranslationWSClient(url)
        await client.connect("ru", "en")
        await client.send_audio(load_fixture_pcm("ru_to_en_short.wav"))
        latencies = []
        async for event in collect_finals(client, timeout=30.0):
            if event["type"] == "translation.final":

## 6. Runtime Budget

| Suite | Mode | Estimated runtime | CI policy |
|-------|------|------------------|-----------|
| TC-01 to TC-23 | Mocked engine | < 30s total | Runs on every PR |
| Integration smoke | Real SeamlessStreaming | < 5 min per test | Manual dispatch only |

The 30s budget for mocked tests is achieved because:
- Mock engine yields events with 50ms simulated latency
- No model loading (engine is injected stub)
- All audio fixture files are loaded from disk (no recording)
- Concurrency tests use `asyncio.gather()` — not serial
