# C3 Quick Capture — быстрая голосовая заметка из меню-бара

Дата: 2026-07-16 · Статус: СПЕКА (дизайн одобрен владельцем 16-07, все три поверхности) ·
Автор: Fable 5. Роадмап: `docs/ROADMAP-2026H2.md` §3.4 (кандидат C3).
Исполнение — после Fable-окна (Sonnet/Opus), двумя волнами C3a/C3b.

## 1. Продукт

Быстрая голосовая заметка, которая НЕ вставляется в активное окно (в отличие от
диктовки Right Option). Владелец выбрал все три поверхности:

1. **Скретчпад-список в меню-баре** — последние заметки, копирование в один клик.
2. **Авто-отправка в Apple Notes / Obsidian** — opt-in настройками.
3. **Плавающее мини-окно скретчпада** — live-текст надиктовки + список заметок.

Триггер: пункт меню-бара + глобальный хоткей **Cmd+Shift+N** (настраиваемый;
⚠️ дефолт затеняет «Новую папку» Finder — владелец предупреждён, смена дефолта
на ревью спеки допустима без изменения дизайна).

## 2. Ядро (переиспользование, почти без правок бэкенда)

- Запись: существующие `start_recording`/`stop_recording` IPC (RecordingCoreService).
  Все сторожа (WakeWordWatchdog is_recording, AudioSelfHealer, brain-lease) видят
  заметку как обычную запись — бесплатно.
- Хранение: обычный history item (privacy-гейты, шифрование, purge, экспорт —
  наследуются) + авто-`add_to_collection` в коллекцию **«Быстрые заметки»**
  (создаётся лениво через `create_collection` при первом использовании — паттерн
  bulk-действий 2026-06-15). `history_id` приходит в ответе `stop_recording`.
- Список заметок: существующий `get_collection_items` (privacy-гейт уже внутри
  history-слоя: в privacy-mode список пуст — принято).
- Новых IPC-методов НЕ требуется (проверено 16-07: `create_apple_note`,
  `get_collection_items`, `add_to_collection`, `create_collection` — все живые).

### 2a. Правила режима «заметка» на Swift-стороне

- Финальный paste НЕ вызывается (решение о вставке живёт в Swift — flow заметки
  просто не зовёт PasteService).
- 🔴 **StreamingPasteController НЕ запускается** для записи-заметки (иначе
  партиалы печатаются в активное окно по ходу — streaming_paste стартует миррором
  startRealtimeOverlayPolling; для заметки этот миррор подавить). RealtimeOverlay
  (индикация записи) — остаётся.
- `paste_status`: заметка не должна выглядеть в истории как «вставка провалилась»
  (`add_history_item` ставит `"failed"` по умолчанию). План выбирает дешёвое из:
  существующее нейтральное значение статуса / не показывать бейдж провала для
  items коллекции «Быстрые заметки». Менять схему HistoryItem — нельзя.
- Dup-ветка: `stop_recording` может вернуть `skipped: duplicate, history_id: None`
  → toast «Заметка совпала с недавней записью — пропущена», в коллекцию не добавлять.
- Взаимное исключение (обе стороны): при активной диктовке/встрече/разговоре
  триггеры заметки отвергаются с toast'ом; при активной заметке Right Option /
  встреча отвергаются аналогично. Реализация: общий guard по существующим
  признакам активной записи (те же Set-причины, что у WakeWordPoller) + для
  пункта меню — NSMenuItemValidation (disabled).

## 3. C3a — меню-бар + хоткей + авто-отправка (волна 1, S-M)

### 3.1 Меню-бар (`main+QuickCapture.swift`, новый extension)

- Пункт «Быстрая заметка ⌘⇧N» рядом с существующим recordItem; во время записи
  заголовок «⏺ Идёт заметка… (нажмите — стоп)».
- Подменю «Быстрые заметки»: последние 7 из `get_collection_items` (off-main,
  AGENT-3), формат «первые ~40 символов… · HH:mm»; клик — копировать полный текст
  в NSPasteboard + toast «Скопировано»; последний пункт «Показать все…» — открыть
  History-панель (существующий фильтр по коллекции, если есть; иначе просто панель
  истории).
- Подменю строится в `menuWillOpen` (паттерн MenuBarRecapView) — без фонового
  поллинга.

### 3.2 Хоткей

- Глобальный Cmd+Shift+N — регистрация рядом с SelectionTranslator (Cmd+Shift+T);
  настройка `quick_capture_hotkey` в Settings-секции «Быстрые заметки» (строка
  вида "cmd+shift+n"; парсер/валидация — как у существующих хоткеев, если общего
  парсера нет — фиксированный набор из 3-4 комбинаций в дропдауне, НЕ свободный ввод).
- Повторное нажатие = стоп. (`report_hotkey_conflict` неприменим: NSEvent-мониторы
  не регистрируются и не конфликтуют — они наблюдают; уточнено разведкой 16-07.)

### 3.3 Авто-отправка (Settings-секция «Быстрые заметки»)

- Чекбокс «Дублировать в Apple Notes»: после финализации —
  `create_apple_note {title: авто-заголовок/первые слова, body: текст}` off-main;
  ошибка — toast, заметка в history не страдает.
- Чекбокс «Синхронизировать в Obsidian»: после финализации — форс-инкрементальный
  Obsidian-синк существующим механизмом (ObsidianSyncManager), только если vault
  настроен; иначе чекбокс disabled с подсказкой.
- Оба default **off**. Настройки: `quick_capture_send_to_notes`,
  `quick_capture_obsidian_sync` (bool, `_BOOL_FIELDS` валидатора).
- Privacy: privacy_mode блокирует обе отправки независимо от чекбоксов (гейт
  на Swift-стороне по privacy-статусу + create_apple_note уже за privacy-гейтом,
  если он transcript-bearing — проверить в плане; если нет — добавить гейт).

## 4. C3b — плавающее мини-окно скретчпада (волна 2, M)

- `QuickCapturePanelController` — паттерн MeetingLivePanelController (floating
  NSPanel: .nonactivatingPanel/.hudWindow/.utilityWindow/.closable/.resizable,
  isReleasedWhenClosed=false, off-screen guard, positionKey
  `KrabEar_QuickCapturePanelPosition`; ВСЕ уроки C2c: панель обязана закрываться,
  у sticky-состояний — выход по таймауту/poll'у).
- Содержимое: зона live-текста текущей надиктовки (SSE
  `realtime.partial_transcript`/`realtime.final_transcript` через общий
  SSESessionDelegate + poll-фоллбэк — канал и паттерн готовы) + список последних
  заметок + кнопки: ⏺/■ (старт/стоп), «Копировать», «→ Notes» (если включено).
- Открытие: настройка `quick_capture_show_panel` (default off) — авто-показ при
  старте заметки; вручную — из подменю «Быстрые заметки» → «Открыть скретчпад».
- Редактирование текста заметки в окне — НЕ в C3b v1 (кандидат на C3c после
  живого использования; фиксируем, чтобы не раздувать волну).
- Визуальная полировка — agy-бриф ПОСЛЕ инженерной сборки (граница Claude/agy
  как в C2c: логика/test-hooks — Claude, стилизация — agy).

## 5. Риски

| Риск | Митигция |
|---|---|
| Партиалы заметки печатаются в чужое окно | 🔴 подавить StreamingPasteController для записей-заметок (2a) + тест на неподключение |
| Гонка заметка↔диктовка↔встреча | общий guard активной записи в ОБЕ стороны + NSMenuItemValidation (2a) |
| Cmd+Shift+N затеняет Finder «Новая папка» | хоткей настраиваемый; дефолт — решение владельца, смена дешёвая |
| Заметки выглядят «paste failed» в истории | решение в плане C3a (2a), схему HistoryItem не менять |
| create_apple_note без privacy-гейта | проверка в плане; при отсутствии — добавить гейт (transcript наружу) |
| Дубликат-скип теряет заметку молча | toast + не добавлять в коллекцию (2a) |
| Панель-зомби / вечные состояния | уроки C2c зашиты в §4 требованиями |

## 6. Не-цели

Голосовой триггер («Hey Jarvis, заметка») — возможная надстройка позже;
редактирование заметки в UI; отдельный store/формат хранения; изменения обычной
диктовки/встречи; новые IPC-методы (если план не докажет обратное по paste_status).

  приложение; заметка видна в подменю и копируется; Notes/Obsidian доставка при
  включённых чекбоксах; swift test + полный гейт-набор проекта.
