# Слияние REST-процесса в backend (§3.1 роадмапа H2) — дизайн-скетч наперёд

Дата: 2026-07-07 · Статус: **СКЕТЧ** (не спека) — материал для гейт-решения после Волны 2.
Автор: Fable 5 (финальная сессия). Цель документа: чтобы решение и стратегия были продуманы
на «дорогой» модели заранее, а будущая спека писалась на Sonnet по этим рельсам.

## Зачем сливать

1. **Конец класса 2-EventBus навсегда** (мост Волны 2 закрывает функциональный гэп, но
   двухшинность остаётся источником будущих сюрпризов).
2. **RAM**: `rest_server.py:472-476` держит СОБСТВЕННЫЕ `AudioEngine`, `StateStore`,
   `Transcriber`, `Translator`, `TTSService` — второй комплект тяжёлого состояния
   (Wave 69 уже ловил дубль GigaAM-воркера на 1.46 GB).
3. **Локи**: межпроцессная сериализация MLX (`mlx_inter_process_lock`, flock) вырождается
   в обычный in-process `mlx_lock` — минус класс таймаутов.
4. **Опс**: один launchd-агент вместо двух, один лог, один lifecycle, один health-статус.
5. **Тест-гигиена**: module-level globals REST — корень задокументированного класса
   chunk-pollution флейков (`patch("backend.rest_server.store")` + reload-вариант). Фабрика лечит.

## Стратегия: strangler в 3 волны (НЕ big-bang)

### Волна M1 — App-factory (чистый рефакторинг, поведение не меняется)
- `create_app(deps: RestDeps) -> Flask` — вся инициализация (app, api, sock, limiter,
  blueprints, ws_stream) уходит в фабрику; зависимости (engine, store, transcriber,
  translator, tts_service, event_bus, live_subs) — поля `RestDeps`, инжектируются.
- Standalone-режим сохраняется: `__main__`-путь строит `RestDeps` из собственных инстансов
  (как сегодня) и вызывает фабрику. **Module-level имена (`store`, `engine`, …) остаются
  как алиасы standalone-инстансов** — все 12 патчащих тест-файлов работают без правок.
- Новые тесты — только через фабрику (изолированный app per-test, конец reload-хакам).
- DoD: поведение бит-в-бит (e2e REST-смок), ubuntu-parity, ни один существующий тест не тронут.

### Волна M2 — In-process режим (опт-ин)
- `rest_in_process_enabled` (default **false**): IPC-процесс поднимает
  `create_app(deps из BackendService)` в daemon-треде через
  `werkzeug.serving.make_server(...)` (управляемый `.shutdown()` в
  `GracefulShutdownHandler`; НЕ `app.run` — у него нет чистого останова).
- Порт тот же :5005 → Swift/VG-клиенты не замечают перехода.
- Мост Волны 2 самовырождается: при shared-шине (`rest bus IS ipc bus`) EventBridge не
  стартует (проверка тождества объекта) — события идут напрямую.
- Канарейка на владельце ≥2 недели: latency-бенчи диктовки, RAM-замер
  (`scripts/memory_baseline.py`), стабильность SSE/WS под нагрузкой.

### Волна S3 — Флип и вывод
- default true → `migrate_to_canonical_launchagent.command`-стиль скрипт: bootout
  rest-агента, удаление plist; `install_rest_launchagent.command` помечается deprecated.
- Standalone-режим НЕ удаляется (dev/тесты/аварийный откат setting'ом).

## Главные риски и как их гейтить

| Риск | Оценка | Гейт |
|---|---|---|
| Латентность диктовки при одновременном REST-transcribe | Сегодня УЖЕ сериализуются межпроцессным flock — конкуренция не новая, меняется только уровень | Перф-гейт CI (p95 +15% бюджет) + ручной бенч до/после |
| flask-sock/SSE тред-модель под `make_server` (threaded) | Проверить: 3 SSE-клиента + WS-стрим + transcribe параллельно | Нагрузочный смок в волне M2 |
| Краш REST-хендлера валит и диктовку | Phase A supervisor уже перезапускает backend; было «два процесса — две зоны отказа» | Осознанно принять; error-boundary вокруг Flask-треда |
| GIL-давление (Flask-парсинг больших аудио-POST) | Аудио уже гоняется base64 через тот же Python | Замер RTF импорта в M2 |
| Тест-миграция (12 файлов патчат module-level) | Алиасы сохраняют совместимость; миграция постепенная | Ни одной правки старых тестов в M1 |

## Гейт-решение (вход в §3.1, после Волны 2)

Идти в слияние, если ВСЕ да:
1. Мост Волны 2 прожил ≥2 недели без инцидентов (события — на нём).
2. Нагрузочный прото-смок make_server+flask-sock (можно сделать ДО M1 за ~час) стабилен.
3. Есть окно на 2-3 волны без конкурирующего приоритета фронта A/B.
Иначе — остаёмся на мосте (он самодостаточен), пересмотр через квартал.

## Оценка

M1 (factory) = M · M2 (in-process) = M · S3 (флип) = S. Всё Sonnet-исполняемо по этому
скетчу + будущей спеке. Скетч НЕ заменяет спеку волны M1 — та пишется по циклу §1 роадмапа.
