| 9.1 | 39 vs «29» роадмапа | Источник истины — инвентаризация черновика (39). Роадмап содержал оценку, не точное число. |

Пункты черновика, оставшиеся вне v1-пресета (решение контролёра — не решать сейчас, не блокирует):
`semantic_search_enabled` (требует рестарт backend — §3.1 №29 черновика, ломает обещание
«мгновенный эффект»), `history_encryption_enabled` (security opt-in, заслуживает отдельного
явного согласия, не тихого включения в общем тапе), `stt_punctuation_llm_pass_enabled` (автор

в одиночку (бессмысленно без gigaam, а gigaam теперь всегда manual), `voice_fingerprint_enabled`
(гейт не подтверждён черновиком). Все пять — кандидаты для будущей волны, не пропадают из виду
(остаются описанными в DRAFT-файле).

## 1. Финальный состав пресета `apply_recommended_setup` (v1)

**10 безусловных** (вердикт ДА черновика §4): `smart_silence_skip_enabled`,
`realtime_silence_filter_enabled`, `auto_dedup_enabled`, `auto_save_transcripts`,
`phonetic_vocab_enabled`, `text_snippets_enabled`, `auto_learn_corrections_enabled`,
`quick_edit_enabled`, `paste_undo_enabled`, `calendar_link_enabled`.

**3 условных, через probe-гейт** (алгоритм §5.3 черновика, без изменений):
`llm_rewrite_enabled` (probe `probe_llm_http`), `action_items_auto_extract` (тот же probe +
privacy-гейт Задачи №0), `stt_sensevoice_enabled` (наличие модели в HF-кэше).

**GigaAM-пара исключена из probe-логики полностью** (решение 9.7) — `stt_gigaam_enabled` и
`stt_language_routing_enabled` НЕ входят в `apply_recommended_setup` вообще, ни как ДА, ни как
УСЛОВНО-ДА с пробником. Остаются `skipped` всегда с причиной `"настройте GigaAM вручную в Настройках"`
независимо от состояния venv на диске.

Итого предлагаемый набор кандидатов на вход probe-логики: **13** (10 безусловных + 3 условных).
Wake word (`wake_word_engine`) — отдельный шаг, не через этот IPC-вызов (решение 9.4).

## 2. IPC-контракт (наследует §5 черновика, без изменений формы)

```
apply_recommended_setup {
    "dry_run": bool = true,
    "keys": list[str] | null   // API поддерживает фильтр; v1 UI его не использует (решение 9.5)
}
→ {
    "ok": true, "dry_run": bool, "tier": "low"|"mid"|"high",
    "applied": [{"key", "old_value", "new_value", "restart_required"}],
    "skipped": [{"key", "reason"}],   // GigaAM-пара — ВСЕГДА здесь с фиксированной причиной
    "rationale": str, "snapshot_id": str | null, "restart_required": bool
}
```

Алгоритм (§5.3 черновика) без изменений, кроме: шаг 4 «для УСЛОВНО-ДА» теперь применяется
только к 3 кандидатам (без GigaAM-пары, которая уходит в `skipped` на шаге классификации,
до probe-логики).

Откат — существующий `restore_settings_backup {snapshot_id}` (§6 черновика), новый код отката
не пишется.

## 3. UI

- **Онбординг**: шаг после `ModelDownloadStep` (образец: `main.swift:1417`
  `runModelDownloadStepThenComplete`) — превью (`dry_run:true`) → «Применить»/«Пропустить».
- **Wake word — отдельный экран** (решение 9.4), встроен в ту же цепочку онбординга, но со своим
  текстом согласия и собственным вызовом (`set_settings {wake_word_engine: "openwakeword"}`),
  НЕ через `apply_recommended_setup`.
- **Настройки**: новая секция по образцу `HistoryPanelController+Calibration.swift` — превью +
  «Применить рекомендуемое» + «Отменить последнее» (снапшот по `reason=before_recommended_setup`).
- **Design-brief для agy** (решение 9.6): будущий план ДОЛЖЕН включать задачу «написать
  `docs/design-briefs/2026-0X-recommended-setup-ui.md`» ПЕРЕД задачей визуальной реализации —
  бриф описывает что нельзя ломать (Auto Layout механику, IPC-контракт) и что улучшить
  (карточка/иконки), затем `agy` исполняет визуал, Sonnet — wiring. Порядок как в
  `reference_gemini_cli_delegation`: brief → agy → ревью диффа контролёром → `swift build`.

## 4. Privacy

`privacy_mode_enabled` всегда проверяется первым — transcript-читающие кандидаты из безопасного
набора (`auto_learn_corrections_enabled`, `action_items_auto_extract`, `auto_dedup_enabled`)
уходят в `skipped` при включённом privacy-режиме. Задача №0 (построчная проверка гейтов) —
обязательный первый пункт будущего плана, не полагаться на «наверное уже гейтится».

## 5. Тест-план и DoD

Наследуются из §10-§11 черновика без изменений, с двумя уточнениями:
- Regression-тест «список безопасных кандидатов» (§10 п.2) теперь явно проверяет, что
  `stt_gigaam_enabled`/`stt_language_routing_enabled` НИКОГДА не попадают в `applied` ни при
  каком входе, включая замоканный «venv существует и валиден» — это осознанная политика (9.7),
  не пробел в проверке предусловия.
- DoD добавляется: design-brief для agy написан и передан ДО задачи Swift-реализации UI.

## 6. Явно вне скоупа

Пять «ВОПРОС»-кандидатов из §0 (semantic_search, history_encryption, punctuation-LLM,
language_routing-solo, voice_fingerprint) — не реализуются в этой волне. GigaAM auto-detect —
явно отвергнут (9.7), не «пока не сделано», а «решено не делать».
