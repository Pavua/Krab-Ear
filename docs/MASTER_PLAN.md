# Krab Ear Master Plan

Дата версии: 2026-02-11
Статус: Active

## 1. Product North Star

Krab Ear должен быть офлайн-first диктовкой для macOS, которая:
- запускается мгновенно;
- стабильно вставляет текст в активное поле;
- никогда не теряет транскрибацию;
- удобнее в ежедневной работе, чем платные аналоги.

## 2. Неизменяемые инварианты

1. Основной поток всегда рабочий: `hotkey -> record -> stop -> transcribe -> paste/history`.
2. История без лимита, с быстрым доступом через пагинацию.
3. При сбое вставки текст остаётся в буфере + истории.
4. Базовый режим — локальный offline STT.

## 3. Must-have набор (в порядке выполнения)

### Block A: Stability Core

- soak-runner на 1k/5k циклов;
- автоотчёт ошибок и латентности;
- проверка сценариев отказа вставки;
- контроль зависаний backend/agent.

Done definition:
- 0 критических падений на soak;
- подтверждённый fallback при paste failure.

### Block B: UX Core

- доступный UI без терминала;
- док/менюбар и быстрый вызов панели;
- читаемая история длинных диктовок;
- единые настройки в одной панели.

Done definition:
- пользователь управляет функциями без терминала и Finder-поиска.

### Block C: Smart Dictation

- realtime preview (best effort);
- профили вставки/форматирования;
- быстрые действия с последней транскрибацией.

Done definition:
- realtime не ухудшает стабильность core-сценария.

### Block D: Power Features

- офлайн-перевод (RU<->EN + расширяемо);
- режим «перевести и вставить»;
- пакетная транскрибация файлов;
- шаблоны/макросы вставки.

Done definition:
- advanced-фичи не ломают core и покрыты smoke-тестами.

## 4. Технический чек-лист для каждого PR

1. Обновлён контракт settings/IPC (если менялся).
2. Добавлен тест или автопроверка.
3. Обновлены `PRD.md`/`ARCHITECTURE.md`/`ROADMAP.md` при архитектурных изменениях.
4. Проверен UX fallback при ошибке вставки.

## 5. Метрики качества

- `paste_success_rate`
- `median_transcribe_latency_ms`
- `p95_transcribe_latency_ms`
- `crash_count_per_1000_sessions`
- `history_panel_open_latency_ms`

## 6. Feature flags

Новые рискованные функции (realtime, перевод, интеграции) добавлять только под флагами, с возможностью полного отката без изменения основного потока.
