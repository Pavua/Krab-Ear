# Очередь ночного прогона

Как пользоваться: владелец отмечает, что разрешено на эту ночь, и уходит.
Сессия идёт по списку сверху вниз, не задавая вопросов. Модель — Fable 5.1,
низкая глубина: решения приняты заранее, платим в основном за чтение кэша.

## Правила ночного прогона

1. 🔴 **Только задачи без развилок.** Если по ходу нужен выбор владельца —
   задача останавливается, факты пишутся в отчёт, следующая берётся дальше.
2. 🔴 **Ничего деструктивного и внешнего**: без удалений без бэкапа, без
   звонков наружу, без публикаций, без правок в чужих репозиториях.
3. **Мержить нельзя**, если это не разрешено явно на эту ночь. PR открывать можно.
4. **Прод не перезапускать под запись**: только `scripts/safe_backend_restart.command`,
   и только если задача этого прямо требует.
5. Результат каждой задачи — проверяемый машиной: зелёный тест, замер, отчёт с числами.
6. Одна сессия, без компактов: кэш живёт, пока контекст стабилен.

Fail-fast стал громким (#1991), но ПРИЧИНА не устранена. Ночью: собрать все

### 2. Сиблинги «немой смерти»
Найденный класс: жёсткий выход без сброса журнала. Прогнать по проекту лензу

обёрток HTTP. Находки — тест + исправление.
